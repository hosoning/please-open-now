# 请在这时打开

面向梦女的私人信箱互动网站。

## 使用方法

1. 直接打开 `index.html` 即可使用（推荐用本地服务器，避免部分浏览器对 file:// 的 IndexedDB 限制）。
2. 部署到任意静态托管（GitHub Pages、Cloudflare Pages、Vercel 等）。

## 本地预览

```bash
# 使用任意静态服务器，例如：
npx serve .
# 或
python3 -m http.server 8080
```

## 功能

- 12 个心情主题，每主题 10 封高质量信件
- 拆信仪式动画
- 本地 IndexedDB 存储完整信件快照
- 历史信箱检索、导入导出
- 名字自定义
- 移动端优先

## 注意事项

数据仅保存在浏览器本地。清除缓存、无痕模式或更换设备可能导致记录丢失。

所有内容均为虚构的角色代入式互动，并非来自真实人物。
